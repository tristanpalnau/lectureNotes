Use the contrapositive to prove the following proposition:

If n is an integer and 3n + 2 is even, then n is even.



///

Proof (contrapositive). Suppose n is not even. It follows that n is odd, so there is  an integer k such that
n = 2k + 1. We have that:

3n + 2 = 3(2k + 1) + 2
           = 6k + 3 + 2
           = 6k + 5
           = 2(3k + 2) + 1

Thus 3n + 2 = 2b + 1, where b is the integer 3k + 2. By the definition of odd numbers, 3n + 2 is odd.
