4. Using the simplest notation possible, describe the elements in the set:

    {x : x ∈ ℤ, x ≥ -5} ∪ {x : x ∈ ℤ, x ≤ 7}


    Answer: the set of all integers (ℤ).

    The first set contains all integers greater than or equal to 5,
    and the second set contains all integers less than or equal to 7.

    The union of these two sets is ALL integers, since the first set goes to positive
    infinity and the second set goes to negative infinity (and they overlap in the middle).

5. Suppose A ⋃ B = A for two sets A and B. What does that tell us about A and B? Explain.

We know that B ⊆ A. 

If A ⋃ B = A, then we know there are no additional elements in A ⋃ B that weren't also in A. 
This tells us that B doesn't contain any elements that weren't also in A. Thus B ⊆ A.




///

6. Suppose A ⋂ B = A for two sets A and B. What does that tell us about A and B? Explain.

We know that A ⊆ B. 

Since A ⋂ B contains only elements that are in both A and B, if A ⋂ B = A 
then every element in A is also in B. Thus A ⊆ B.

7. Suppose A, B, and C are sets.
    a) If A ⋃ C = B ⋃ C, must A = B? Either provide a counterexample (with specific sets
        for A, B, and C) or explain why this must be true.


    No. As a counterexample, suppose A = {1,2}, B = {1}, and C = {2}. Here we have that
    A ⋃ C = B ⋃ C = {1,2}, but A ≠ B.


///

    b) If A ⋂ C = B ⋂ C, must A = B? Either provide a counterexample (with specific sets
        for A, B, and C) or explain why this must be true.


    No. As a counterexample, suppose A = {1,2,3}, B = {1,2,4}, and C = {1,2}. Here we have that
    A ⋂ C = B ⋂ C = {1,2}, but A ≠ B.
