OR introduction

          P                      Q
OrI1 : ---------        OrI2 : ---------
        P ∨ Q                   P ∨ Q




Syntax:

OrI2(lineWithRight)

///////////////////////////////////////////

OR elimination


Idea:
- If an OR statement is true, what do we know?

p ∨ q  as a claim
know: either p is true, or q is true (or both)




- What if we can reach the same conclusion no matter which side
    of the OR is true?


assume p is the one that's true
    ...
    reach conclusion

now assume q is the one that's true
    ...
    reach SAME conclusion
afterwards, can claim the conclusion is true 
    (because it doesn't matter which of p or q led to it)


Rule summary:


               SubProof(          SubProof(
                  Assume ( P ),      Assume ( Q ),
      P ∨ Q       ...                ...
                  R                  R
               ),                  ),
OrE : ---------------------------------------------
                         R


How does this relate to programming?


if (condition) {
    some result
}
else {
    some result
}

--> what do we know is true here? some result
