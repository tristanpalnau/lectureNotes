OR elimination


Idea:
- If an OR statement is true, what do we know?






- What if we can reach the same conclusion no matter which side
    of the OR is true?






Rule summary:


               SubProof(          SubProof(
                  Assume ( P ),      Assume ( Q ),
      P ∨ Q       ...                ...
                  R                  R
               ),                  ),
OrE : ---------------------------------------------
                         R


How does this relate to programming?


if (condition) {
    some result
}
else {
    some result
}

--> what do we know is true here?
