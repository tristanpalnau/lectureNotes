Mathematical induction.

Tool for proving some claim P(n) holds for all natural numbers n



The induction domino effect:

    ( P(1) ∧ ∀ k (P(k) → P(k+1)) ) → ∀ n P(n) 




What is this saying?
    P(1)? the claim is true for n = 1

    ∀ k (P(k) → P(k+1))? for all k, if it's true for one P(k) then it's true for P(k+1)



Putting it all together:



English translation?


How will we prove P(1)? 
    choose 1st element in domain and show that claim holds for it.

Revisit our example:

We want to prove that for any positive integer n:

    1 + 2 + ... + n = n*(n+1)/2


The above claim is P(n)


Proof by induction.

BASE CASE: We must prove the claim holds for the first positive integer n. 
n = 1. We have that the left side of the claim is 1 and the right side is 1*1+1/2 = 1.
The two sides are equal so the base case holds.

INDUCTIVE STEP: We assume the inductive hypothesis - that 1 + 2 + ... + k = (k*k)+1/2 for some fixed positive integer k.
We must show that our claim holds for k+1. That is, we must show that: 
1 + 2 + ... + k + (k+1) = ((k+1)(k+1))+1/2

We have that:
    1 + 2 + ... + k + (k+1) = (k*k)+1/2 + (k+1) (by inductive hypothesis)
                            = ... recall
                            ...
                            = ((k+1)(k+1))+1/2
