#5: Use proof by contradiction to prove that the sum of a rational and
irrational number is irrational.

How to write as an IF/THEN?

If we have a rational number r and an irrational number i, then
    r+i is irrational.


Rational definition?

a number x is rational if x = p/q where p,q are integers and q!=0.



How to start the proof? 
    Let r be a rational number and let i be an irrational number.
    Assume, for the sake of contradiction, that i+r is rational.

    Since r is rational, r = p/q where p,q are integers and q != 0.
    Since i+r is rational, i+r = a/b where a,b are integers and b != 0.

    i = (i+r) - r 
      = a/b - p/q

    (want a contradiction)

Example.

Prove that {x : x = 4k + 2, k ∈ ℤ} ⊆ {x : x = 2a, a ∈ ℤ}

A = {x : x = 4k + 2, k ∈ ℤ} 
B = {x : x = 2a, a ∈ ℤ} 

A: what elements?  every other even number
    (just the evens between the multiples of 4)


B: what elements? even numbers 


Proof that A ⊆ B.

Let x ∈ A. Then x = 4k + 2 where k ∈ ℤ.
We have that:
    x = 4k + 2
      = 2(2k + 1)

Thus x = 2a, where a is the integer 2k+1, and so x is in B.

Subst_<(m, n) and Subst_>(m, n)



Deduce(
    ...
    m ( LHS == RHS ),      //must be an equivalence
    ...
    n ( claim ),
    ...
    j ( result )              by Subst_?(m, n)
)

result rewrites claim by doing a find/replace between LHS and RHS


**The < points at the value we are REPLACING
    Subst_<(m, n) rewrites claim by replacing all LHS with RHS

    Subst_>(m, n) rewrites claim by replacing all RHS with LHS
