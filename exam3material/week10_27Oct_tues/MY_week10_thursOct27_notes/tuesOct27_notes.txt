Review:

The induction domino effect:

    ( P(1) ∧ ∀ k (P(k) → P(k+1)) ) → ∀ n P(n) 

P(n) is a claim over (usually) natural numbers.

Steps for an induction proof?
    If we can prove ( P(1) ∧ ∀ k (P(k) → P(k+1)) )
    ...
    we are promised: ∀ n P(n) (this is the claim we're trying to prove)

P(1): base case -prove our claim for the smallest value in our domain

∀ k (P(k) → P(k+1)): inductive step
    Assume it's true for P(k) for some random k in our domain
    Prove it's still true for P(k+1)

Example: Prove that the sum of the first n odd numbers is n^2.

    (what is our domain?)

base case would be the sum of the first 1 odd number
    sum of first 1 odd          does 1 = 1^2?
    sum of first 2 odds         does 1+3 = 2^2?
    sum of first 3 odds         does 1+3+5 = 3^2?

domain is natural numbers.

How can we express the sum of the first n odd numbers more formally?

In general:

    1 + 3 + 5 + ... + (nth odd) = n^2

So, what is our claim?

    1 + 3 + 5 + ... + (2n-1) = n^2

Proof by induction.

Base case. We must prove our claim for the smalles natural number n = 1. We have that 1 = 1^2 so the base case holds.

Inductive step. We assume the inductive hypothesis, that: 
    1 + 3 + 5 + ... + (2k-1) = k^2
for some fixed natural nuber k. We must show that:
    1 + 3 + 5 + ... + (2k-1) + (2(k+1)-1) = (k+1)^2

We have that: 
    1 + 3 + 5 + ... + (2k-1) + (2(k+1)-1) = k^2 + (2(k+1)-1)   (by inductive hypothesis)
                                          = k^2 + 2k + 1
                                          = (k+1)^2        

The inductive step holds.
Thus we have shown with induction that for all natural numbers n:
    1 + 3 + 5 + ... + (2n-1) = n^2

Bad induction, example 1.

Use induction to prove that in any nonempty set of n horses, 
all horses are the same color.

domain? natural numbers.

Base case. We must prove that our claim holds for the 
smallest natural number, n = 1.We have that a set of 1 horse,
all horses would have the same color (because there's only 1 horse).

inductive step. We assume the inductive hypothesis, that in any set of
k horses where k is a natural number, that all k horses have the same color.
We must show that if we have a set of k+1 horses, that all horses have the same color.

Recursively defined functions.


To define a function whose domain is the set of natural numbers
(or some other set of integers with a lowest value)

Base case: Specify the value of the function at 1 (or some other
    lowest value). (There may be more than one base case.)


Recursive step: Give a rule for finding the value of the function
    at all bigger integers in our domain using its smaller values
