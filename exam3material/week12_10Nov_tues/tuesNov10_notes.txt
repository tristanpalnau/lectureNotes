    ),
    Ensures(
        postcondition,

    )

Four steps:

1) What should be done before calling the function?

prove all its preconditions about what WE are passing as the parameter


2) What can the function itself do with the preconditions?

list all preconditions as premises


3) What must the function do with the postconditions?

prove each postcondition about the value being returned


4) What can the calling code do with the postcondition after
    the function returns? 

list each postcondition as a premise using the values passed as parameters
    and the place the return value is being saved
