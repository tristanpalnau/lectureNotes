Example: prove that the product of two even integers is even.


If our domain is integers and we have the predicate Even(x), how
would you write this statement in predicate logic?

∀ x ∀ y (Even(x) ^ Even(y) -> Even(xy))



What's the idea of proving this in predicate logic?

Let x and y be integers. Assume x and y are even. We must show that
xy is even. Since x is even, we have that x = 2k for some integer k.
Since y is even, we have that y = 2m for some integer m.

We have that:
    xy = (2k)(2m)
        = 2(2km)

Thus xy = 2b where b is the integer 2km. We have that xy is even.

Example.

The square of any odd integer is odd.

    ∀ x (Odd(x) -> Odd(x^2))

Direct proof:

Let x be an odd integer. We must show that x^2 is also odd.
If x is an odd integer, then x = 2k + 1 for some integer k.

We have:
    x^2 = (2k + 1)^2
        = (2k+1)(2k+1)
        = 4k^2 + 4k + 1
        = 2(2k^2 + 2k) + 1

Thus x^2 = 2b + 1 where b is the integer 2k^2 + 2k, and so x^2 is
odd by definition.

Proof by contrapositive template:

Proof by contradiction.

- same idea as PbC in natural deduction

- assume that what you are trying to prove is not true

- try to get a contradiction

- conclude what you are trying to prove is true after all




/////////////////////////

Proof by contradiction template 1 (trying to prove P)


Suppose, for the sake of contradiction, ¬P.
...
C ^ ¬C.

We have a contradiction between C and ¬C, so P must hold.





//////////////////////////

Proof by contradiction template 2 (trying to prove If P, then Q):


Assume P.
Suppose, for the sake of contradiction, ¬Q.
...
C ^ ¬C.
We have a contradiction between C and ¬C, so Q must hold.

Example (use proof by contradiction):

If x^2 is even for an integer x, then x is even.

(which template? 2)  

Assume x^2 is even for some integer x. Suppose, for the sake of
contradiction, that x is odd.

Since x is odd, we have that x = 2m + 1 for some integer m.

Squaring both sides of x = 2m + 1, we have:
    x^2 = (2m+1)^2
        = (2m+1)(2m+1)
        = 4m^2 + 4m + 1
        = 2(2m^2 + 2m) + 1

Thus x^2 = 2b + 1 where b is the integer 2m^2 + 2m, and so x^2 is odd.
This is a contradiction with our previous assumption that x^2 was even.

Thus x is even.

...goal: contradiction

Definitions: "rational" / "irrational"

A number r is *rational* if r = p/q for some integers p and q,
where q ≠ 0.



Any number that is not rational is irrational,
and any number that is not irrational is rational.

Example: use proof by contradiction to prove that sqrt(2)
is irrational.

(which template?  1 [just a statement])


Suppose, for the sake of contradiction, that sqrt(2) is rational.
Since sqrt(2) is rational, we can write sqrt(2) = p/q where 
p and q are integers and q is not 0. We choose choose p and q 
to have no common factors, such that p/q is fully reduced. 

Squaring both sides of sqrt(2) = p/q, we have that:
    2 = p^2/q^2

Multiplying both sides by q^2, we have that:
    2q^2 = p^2

Thus p^2 = 2b where b is the integer q^2, and so p^2 is even
by definition. Thus p is also even by our previous proof.

Since p is even, p = 2k for some integer k. Plugging in p = 2k 
to our previous equation on line 306, we get:
    2q^2 = p^2 
        = (2k)^2
        = 4k^2

We have 2q^2 = 4k^2. Dividing both sides by 2 yields:
    q^2 = 2k^2

Thus q^2 = 2a where a is the integer k^2, and so q^2 is even by 
defintion. We have that q is also even by our previous proof.

Since p and q are both even, they share 2 as a common factor. This
contradicts with our previous assumption that they share no
common factors. 

Thus sqrt(2) is irrational.

...goal: contradiction
