SOUNDNESS and COMPLETENESS of natural deduction in
    propositional logic

    "provable": prove using natural deduction
    "true": demonstrate an argument with truth tables


SOUNDNESS: if all arguments that are provable are actually true 

p ∧ q 
--------
p


COMPLETENESS: if all true arguments are provable 





--> what would it mean if a proof system was unsound?
    it would mean I could prove untrue things....baaaad


--> what would it mean if a proof system was incomplete?
    ok...would mean there were true arguments I couldn't prove






Propositional logic is both SOUND and COMPLETE.



Using natural deduction to prove the sequent:
    P1, P2, ..., Pn ⊢ q


Is equivalent to using truth tables to show that whenever
    P1, P2, ..., Pn
are true, then q is also true

Sets.

A set is an unordered collection of elements


{1,1,3,5,7} = {1,3,5,7} = {7,3,1,5}



∈: is in, exists in

    x ∈ A  means? x exists (is an element in) set A

    x ∉ A  means? x does not exist (is not an element in) set A



Example: A = {1,4,7,11,20}

    1 ∈ A 
    2 ∉ A



- Common sets in math:

    ℕ: natural numbers (integers 1 and bigger)
    ℤ: whole numbers (all integers)
    ℚ: rational numbers (written as a fraction)
    ℝ: real numbers (can be represented on the number line)
    ℂ: complex numbers (can be written as a + bi)
    ∅: empty set, {}

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ

⊂: subset
